Identificar cartucho o rejilla DE

Un cartucho o una rejilla DE se identifica con el modelo del tanque, la cantidad de elementos y la medida. Un nombre genérico de cartucho no es un ajuste, y esta página no asigna un número de pieza.

  1. Fotografie la etiqueta del tanque y el estilo de válvula o abrazadera.
  2. Cuente cartuchos o rejillas y mida el elemento que está instalado.
  3. Fotografie el múltiple, el tubo central o la válvula de aire si eso falló.
  4. Pare si falta el modelo del tanque. Una rejilla medida sin el tanque sigue siendo una duda de ajuste.

Los cartuchos de spa tienen otra lista, con largo, diámetros y tapas. No copie un cartucho de spa a un tanque de piscina desde esa página.

Preguntas

¿Qué identifica un cartucho o una rejilla DE?

El modelo del tanque, la cantidad de elementos y la medida. La biblioteca de PartSnap pide cantidad y altura de rejillas, forma del múltiple y la válvula de aire cuando la pieza es una rejilla DE.

¿SplashLens publica un número de cartucho?

No. Esta página no lista un número de cartucho, rejilla o múltiple. Compare la placa del tanque y las medidas con el diagrama actual antes de ordenar.
