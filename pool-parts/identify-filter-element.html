Identify a pool filter cartridge or DE grid

A pool filter cartridge or DE grid is identified from the tank model, element count, and measured size. A generic cartridge name is not a fit, and this page does not assign a part number.

Proof to capture

The public PartSnap library's filter example is a DE grid or manifold: tank model, grid count and height, manifold shape, and the air-relief assembly. A cartridge needs the same tank plate plus length and end-cap style. Spa cartridges already have a separate checklist for length, diameters, and end caps; do not copy a spa cartridge into a pool tank from that page.

  1. Photograph the filter tank label and the valve or clamp style.
  2. Count cartridges or grids and measure the element that is actually installed.
  3. Photograph the manifold, standpipe, or air-relief part if it is what failed.
  4. Stop if the tank model is missing. A measured grid without the tank model is still an open fit question.

No part number on this page

Square footage, pleat count, and grid height are clues for the counter. They are not a part number. Confirm the element against the filter's current diagram.

Questions

What identifies a pool filter cartridge or DE grid?

The filter tank model, the element count, and the measured size. The PartSnap proof library asks for grid count and height, manifold shape, and the air-relief assembly when the part is a DE grid.

Does SplashLens publish a filter cartridge part number?

No. This page does not list a cartridge, grid, or manifold part number. Compare the tank plate and measurements with the current filter diagram before ordering.
