What It Means

Actuator Turns Wrong Direction

Likely Causes

  • Toggle switch set opposite desired direction
  • Cams adjusted incorrectly
  • Valve mounted 180 degrees from expected orientation

Next Checks

  1. Use actuator toggle switch to reverse direction if appropriate
  2. Mark original cam positions before adjustment
  3. Adjust open/close cams in small steps
  4. Verify automation labels match actual valve function
