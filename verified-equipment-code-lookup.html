Verified equipment code lookup

The only code meanings on this site that cite a manufacturer troubleshooting guide are Hayward HeatPro LP, HP, HI, and FLo, and only for models listed in that guide. Other published codes still need the current manual for the installed model.

Guide-scoped HeatPro answers

  • LP — low-pressure switch
  • HP — high-pressure switch
  • HI — high-pressure switch
  • FLo — water-pressure switch

The cited source is the Hayward/Summit Heat Pump Troubleshooting Guide. Match the model plate before using a code meaning. These pages are not a diagnosis.

Questions

Which equipment codes on SplashLens cite a manufacturer guide?

Hayward HeatPro LP, HP, HI, and FLo. Each answer is limited to the models listed in the linked Hayward/Summit heat-pump troubleshooting guide, including the guide's HP21004T coverage note. Other HeatPro revisions need their own current manual.

What if the code is not one of those four?

Use the current manual for the installed model. SplashLens withholds a meaning for several unverified families instead of guessing, including selected Jandy, Raypak, AquaCal, Beatbot, and Sta-Rite entries.
