Pump

Impeller with worn molded number

PartSnap should look for vane shape, shaft seal context, pump family, and a second proof photo of the pump label.

  • Needed proof: model plate
  • Needed proof: diameter or stamped number
  • Escalate when number is unreadable
Callback risk: medium until the model and impeller dimensions are confirmed.
Sanitizer

Salt cell with faded label

Use unions, cable connector, controller model, cell length, and flow switch context to narrow the family without pretending certainty.

  • Needed proof: controller label
  • Needed proof: cell body markings
  • Verify before selling replacement
Callback risk: high when only the cell body photo is available.
Robot

Cleaner track or brush

Robot parts often look similar across families. PartSnap should ask for cleaner model, power supply label, track profile, and basket style.

  • Needed proof: robot serial/model
  • Needed proof: track width/profile
  • Escalate to vendor packet
Callback risk: medium because cleaner families share visual parts.
Automation

Board, relay, or actuator

Automation work needs safety language and board/box model proof. The app should help package a cleaner senior-tech ask.

  • Needed proof: enclosure label
  • Needed proof: board revision
  • No electrical repair claim
Callback risk: high without qualified verification.
Lighting

Nicheless light or transformer

Lighting examples should ask for voltage, niche/fixture style, transformer label, and GFCI behavior before any recommendation.

  • Needed proof: voltage
  • Needed proof: fixture family
  • Qualified electrical work only
Callback risk: high until voltage and fixture family are confirmed.
Filter

DE grid or manifold

PartSnap should prompt for tank model, grid count/height, manifold shape, and air-relief assembly proof.

  • Needed proof: filter model
  • Needed proof: grid size/count
  • Save to proof passport
Callback risk: medium when grids are measured but tank model is missing.
Heat Pump

Heat pump sensor or board clue

Use model plate, displayed fault, ambient temperature, water temperature, flow condition, and qualified service boundary before recommending direction.

  • Needed proof: model/serial plate
  • Needed proof: fault display
  • Escalate sealed-system work
Callback risk: high when refrigerant or electrical diagnosis is implied.
Chemical Control

ORP, pH, feed pump, UV, ozone, AOP

Controller proof should include probe age, calibration standard, flow cell condition, tank level, feed tube condition, and manual test comparison.

  • Needed proof: manual test
  • Needed proof: controller screen
  • Qualified commercial rules apply
Callback risk: high when automation readings disagree with manual tests.
Smart Sensor

App-connected sensor or cloud fault

Connected equipment needs app screen, firmware/app status, Wi-Fi path, power proof, and local fallback checks before blaming the part.

  • Needed proof: app error
  • Needed proof: local controller status
  • Document cloud/offline context
Callback risk: medium until local and cloud signals agree.
Spa Pack

Topside, heater tube, sensor, flow switch

Spa parts need controller ecosystem proof first: Balboa, Gecko, Waterway NEO, OEM-branded pack, or unknown.

  • Needed proof: pack label and display code
  • Needed proof: filter, water level, and flow/circ pump context
  • Escalate GFCI, high-limit, and dry-heater repeats
Callback risk: high when a controller part is guessed from only a topside code.
AOP / Ozone

Module, check valve, tubing, status light

Ozone, UV, and AOP proof should include the module label, status light, lamp age, injector/check-valve condition, tubing route, and flow proof.

  • Needed proof: water in tubing or failed check valve
  • Needed proof: status light/app alert
  • Qualified electrical boundary
Callback risk: medium-high when flow and status-light evidence are missing.
Chemical Control

ORP, pH, probes, feed pumps

Automation readings need manual test comparison, calibration proof, probe age, flow-cell condition, and feed-line/tank state.

  • Needed proof: manual water test
  • Needed proof: calibration standard/date
  • Document overfeed or lockout risk
Callback risk: high when app readings disagree with manual testing.
Valve

Actuator, diverter, lid, union

Prompt for pipe size, valve body markings, actuator model, lid screw pattern, and O-ring dimensions.

Heater

Old label and control display

Capture the display code, heater model, gas/electric context, serial plate, and manual reference before field action.

Cover

Cover motor, key switch, sensor

Ask for control box label, motor plate, switch style, cover brand, and qualified-safety verification.

Smart Backyard

Relay, valve actuator, RS-485, app pairing

Connected Pool Network asks for the controller family, app status, device assignment, wiring label, and what changed before the failure.
