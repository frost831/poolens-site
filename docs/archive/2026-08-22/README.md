# SplashLens Site Archive - 2026-08-22

This archive keeps old evidence and one-off working files available without leaving them in active working folders.

## Contents

- `outreach/` - historical outreach prep, scrape output, screenshots, press packets, and dated send packs.
- `reports-and-handoffs/` - older site handoffs, audits, and cleanup reports.
- `tools/` - one-off helper scripts that are no longer active reusable tools.
- `outreach-move-manifest.json` - machine-readable source-to-archive move list for outreach artifacts.

Do not send outreach from this folder. Use `docs/outreach/` for current operations.
