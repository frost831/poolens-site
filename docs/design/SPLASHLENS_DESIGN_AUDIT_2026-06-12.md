# SplashLens Design Audit - 2026-06-12

## Verdict

No. The site is now safe enough to support outreach, but it is not the absolute best SplashLens can be.

It feels credible, functional, and specific to pool techs. It does not yet feel like the sharpest possible product surface for a field utility that wants trade media, creators, and working techs to take it seriously.

## What Is Working

- The headline has a real field moment: "Stuck at the Equipment Pad?"
- The first viewport explains the core job better than a generic SaaS hero.
- The trust patch is now live: no visible `500+` claim, no fake named testimonials, and scenario cards are labeled as use cases.
- The site and app both return HTTP 200.
- pSEO sitemap still has 195 URLs.
- Desktop and mobile checks show no horizontal overflow and no console errors.

## Main Design Problems

1. The page is too long for the first cold-click job.
2. The palette is too one-note blue.
3. The hero is good but not decisive enough.
4. The feature grid overwhelms.
5. Mobile has too much stack depth.
6. Pricing appears before enough proof.

## Best-Next Redesign Direction

Build a tighter outreach landing variant for `splashlens.com/field-reference` or as the homepage:

- First viewport: one large app workflow screenshot, headline, 2 CTAs, no mini-card clutter.
- Proof band: 180+ current entries, no account, manual tools offline, iOS live.
- Three workflow sections only: code lookup, PartSnap verification, offline manual tools.
- Trust section: not diagnosis, verify against label/manual, no affiliation, affiliate disclosure.
- Creator/editor block: screenshots available, technical feedback welcome, contact path clear.

## Priority Fixes

P0 - Already fixed/deployed:

- Removed stale/fake `500+` public claims from live homepage.
- Replaced fake testimonial presentation with illustrative use-case labels.
- Replaced confusing PoolLens/SplashLens brand-history paragraph with direct product positioning.

P1 - Should do before scaling the drip:

- Create a shorter outreach-specific landing page.
- Add one strong product screenshot above the fold.
- Reduce feature grid from 13 cards to 6 or fewer on cold traffic pages.
- Move pricing lower or behind a scanner upgrade explanation.

P2 - Nice but meaningful:

- Add a one-page PDF for distributors/software/training channels.
- Add a media kit page with logo, screenshots, short description, and founder contact.
- Add a visible for-editors/creators contact block.
